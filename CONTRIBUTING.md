# Branch Naming Convention

- `feature/<short-description>` — new functionality (e.g. `feature/item-catalogue`)
- `fix/<short-description>` — bug fixes (e.g. `fix/stock-count-error`)
- `chore/<short-description>` — tooling, config, docs (e.g. `chore/update-readme`)

# Commit Message Style
Use present tense, concise: `Add Item entity and repository`, not `Added` or `Adds`.
